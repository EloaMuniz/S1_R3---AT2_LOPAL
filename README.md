### Exercício 6
 Faça um programa que peça um número inteiro e determine se ele é ou não um número primo.

- Um número primo é aquele que é divisível somente por ele mesmo e por 1.

Dica: Utilize o operador aritmético %, que retorna o resto da divisão de dois números.

<img width="302" height="209" alt="image" src="https://github.com/user-attachments/assets/7bb16d68-a4a6-43f2-ada4-5fb2f3871478" />

  
- #### Explicação:
 O código verifica se um número inteiro é primo. Se o valor for menor ou igual a 1, ele é descartado. Caso ele não for, o código busca por divisores entre 2 e o número digitado, se encontrar algum, o número não é primo. No final o resultado aparece na tela.
